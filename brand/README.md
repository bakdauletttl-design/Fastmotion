# Фирменный стиль HypeCut

Тёмный фон, белый текст и один яркий акцент. Основной — изумрудный `#2EE59D`, есть темы фиолетовая `#9D6BFF` и оранжевая `#FF6A2B`.
Акцент используется скупо: главная кнопка, LIVE, момент на шкале, активные элементы.

- `tokens.json` — цвета, шрифты, скругления, отступы, анимации. Источник правды для ПК и мобильного приложения.
- `hypecut/static/brand.css` — те же токены как CSS-переменные для веб-интерфейса.

Шрифты: Unbounded (логотип и заголовки), Inter (весь остальной текст). Оба бесплатные, Google Fonts.
